国内推广：五大平台的完整打法

国内的流量高度集中在几个平台上。与其到处撒网，不如先搞清楚「我的用户在哪个平台、我适合做哪一个」，然后把一个平台做透。下面每一节都按同一套结构写：适合谁、第一步做什么、花多少钱、盯什么指标、别踩什么坑。

先看全局：一张渠道选择表

很多人的第一个错误是「先选渠道，再想内容」。正确的顺序反过来：先明确你的用户「在哪里解决问题」，再去那个地方。下面这张表帮你快速定位。

你的情况优先做的渠道为什么可承受的最慢节奏
工具 / 软件 / B2B百度 SEO → 知乎 → 行业社区用户遇到问题会主动搜，且决策理性、看重专业度3–6 个月起量
电商 / 课程 / 本地生意小红书 → 抖音 → 搜索承接消费决策靠「看到别人用了」，需要先种草再收割2–8 周见效
App / 小游戏应用商店 ASO → 短视频 → 投放下载入口在商店，ASO 是免费且必须做的地基2–4 周见效
个人 IP / 内容创作选定一个平台日更IP 靠的是高频出现，铺 5 个平台等于都不做1–3 个月起量
社区 / 社群产品垂直社区 → 私域社区靠「人」，冷启动必须自己先当最活跃的用户1–2 个月
一条经验如果你只有一个人，「选一个平台做 3 个月」几乎总是优于「选三个平台各做 1 个月」。前者的复利来自内容和账号权重，后者什么都不会留下。

一、搜索：需求最明确的地方

它适合谁

产品能用一句话描述清楚、用户会主动去搜的，都适合：PDF 转 Word、装修报价单模板、CRM 系统、雅思培训、附近健身房。反过来说，如果你的产品是「用户不知道自己需要」的（比如新的社交玩法），搜索帮不上忙。

第一步做什么

  1. 先挖词，不要先做页面。用百度指数、5118 找出 3–5 个「有人搜、竞争不激烈」的长尾词，标准是：搜出来前几名都是小网站的、内容质量一般的词。
  2. 一页只解决一个问题。每个主推词对应一个独立落地页，标题写成「核心词 + 差异化卖点」，正文开头就给结论和步骤。
  3. 提交收录。在百度搜索资源平台提交 sitemap，开通普通收录。这一步不做，后面的内容再好也可能几个月不被收录。
  4. 把「信任位」补齐。用户搜你品牌名时，如果只有官网、没有百科/知道/媒体报道，转化率会明显低一截。

花多少钱

SEO 本身免费，成本是时间：一篇能排上词的长文大约 2–4 小时。竞价（SEM）则按点击付费，生活服务类 1–5 元/次点击，教育、医美、金融类 10–50 元甚至更高。

盯什么指标

收录页数 → 目标词排名 → 自然搜索点击量 → 落地页转化率。不要用「访问量」做唯一指标，搜索来的流量如果转化率是 0，排名再高也没意义。

最常见的坑新站前 3 个月收录慢是正常的，别急着放弃，也别去买「包上首页」的外链或站群服务——被 K 站之后，之前所有积累都会归零。另外国内做百度推广需要 ICP 备案，这是硬门槛，越早准备越好。

二、小红书：种草的第一阵地

它适合谁

面向女性用户、决策依赖「视觉 + 真实体验」的产品：美妆、家居、母婴、穿搭、餐饮、旅拍、课程、本地服务。如果你的成交靠「看到别人用了觉得不错」，这里就是主战场。

第一步做什么

  1. 先做 30 篇「搜索型」笔记，而不是「推荐型」笔记。比如「小户型收纳怎么做」比「我家超好用的收纳箱」更容易被搜到，也更容易持续带量。
  2. 把账号做成真人。有头像、有简介、有生活化内容。纯导购号会被限流。
  3. 关键词布局要前置。标题和正文前两行必须出现用户会搜的词，小红书的搜索权重和内容相关性高度绑定。
  4. 数据好的笔记再花钱。用聚光把自然互动率高的笔记加热，比直接投效果广告便宜得多。

花多少钱

自己运营免费，成本是持续产出的时间。KOC（粉丝 1000–5 万）合作常见 300–3000 元/篇，重点看真实互动率（3% 以上算健康）；KOL 5000 元起，中小品牌通常不划算。

盯什么指标

笔记互动率（点赞/收藏/评论 ÷ 曝光）→ 搜索词下的笔记排名 → 主页访问量 → 私信/店铺转化率。收藏率比点赞率更重要，它代表「以后要用」的真实需求。

最常见的坑一是用绝对化用语（「最」「第一」「保证」）被限流；二是不报备就发商业笔记，被判定为软广后限流甚至封号——通过蒲公英下单的合作笔记才有投放资格；三是只发产品不发场景，用户看不出「这和我有什么关系」。

三、抖音：量最大，也最考验内容

它适合谁

能持续产出视频的团队；客单价不高、决策快、能靠视觉展示的产品；本地生意（同城流量非常便宜）。如果你的产品一句话说不清、又要长时间教育用户，抖音的效率通常低于搜索和内容平台。

第一步做什么

  1. 先测 20 条素材，而不是先投钱。同一个卖点换 20 种前 3 秒的开头，看哪条完播率明显更高——前 3 秒决定了 80% 的结果。
  2. 把抖音当搜索用。抖音搜索的流量占比越来越高，「关键词型」视频（如「XX 怎么选」）能持续带量，比纯爆款更稳定。
  3. 完播率优先于一切。先把视频做短、把结论前置，再考虑画面精美。
  4. 跑通的素材再上信息流。自然流量表现差的内容，投放也救不回来。

花多少钱

自然运营免费但极其耗人力（一人一天最多产出 2–3 条像样的视频）。信息流投放按 oCPM 计费，千次曝光约 20–60 元；App 安装常见 5–30 元/个。

盯什么指标

前 3 秒完播率 → 整体完播率 → 互动率 → 主页/购物车点击率。投放端再加一个：单次转化成本。

最常见的坑把抖音当「发广告的地方」。抖音的算法奖励「用户愿意看完的内容」，不奖励「说清楚产品的内容」。另外，不要一开始就追求爆款——1000 个精准的搜索流量，比 10 万泛流量更能成交。

四、微信生态：把流量变成资产

它适合谁

所有人都该做，但重点是两类：复购型生意（餐饮、零售、教育）和高客单型生意（B2B、家装、咨询服务）。因为微信是唯一能把「一次获客」变成「可以反复免费触达」的地方。

第一步做什么

  1. 先做承接，再做推广。没有企业微信和社群，广告带来的流量第二天就流失了。
  2. 设计一个「钩子」。资料包、模板、免费试用、立减券——用户要有理由留下联系方式。
  3. 公众号 + 视频号 + 搜一搜一起做。公众号吃搜索和转发，视频号吃推荐流量，搜一搜是微信内免费的长尾入口。
  4. 企业微信做标签和分层。不同的用户发不同的内容，这是私域效率的核心。

花多少钱

几乎是免费的：企业微信、公众号、视频号都不需要付费开通。主要成本是人力——私域是一件需要长期有人管的事。短信唤醒 0.03–0.06 元/条，但要先获得授权。

盯什么指标

加好友数 → 好友通过率 → 社群活跃度 → 私域成交额与复购率。最重要的一个数是「单个好友贡献的月收入」，它决定了你能承受多高的获客成本。

最常见的坑把用户拉进群就开始刷广告。私域的本质是「值得被留在通讯录里」，先提供价值再谈成交。另外注意合规：微信禁止多级分销（三级及以上返佣），也禁止诱导分享。

五、知乎 / B 站 / 社区：慢但持久

它适合谁

需要建立专业信任的产品：B2B 服务、专业工具、课程、咨询、医疗健康类。也适合预算为零、时间充裕的个人。

第一步做什么

  1. 找「已经被问了很多次但答案很差」的问题。回答它，并且比现有答案更完整、更可操作。
  2. 先给方法，最后一句才提产品。社区对广告的容忍度极低，但对干货的传播意愿极高。
  3. 一篇内容多处复用。同一份内容改写成知乎回答、B 站脚本、公众号长文、小红书笔记——这是个人团队唯一可行的内容策略。
  4. 坚持 3 个月以上。这类渠道的回报是「内容会一直被搜到」，前期几乎看不到效果。

花多少钱

基本免费。知+ 等付费形式 2–10 元/次点击，量不大但线索质量高，适合高客单产品。

盯什么指标

内容阅读量 → 互动（赞同/收藏）→ 主页访问量 → 私信咨询数。B 站额外看「三连率」和「播放完成率」。

最常见的坑一是硬广被折叠、被踩；二是写完就发、不做后续维护——知乎回答是可以持续编辑优化的，排名会随着互动和收藏上涨。另外，别在每个回答里都塞同一段产品介绍，这种「万能模板」很容易被识别。

付费投放怎么选

付费投放不是「先花钱」，而是「先用免费渠道验证了转化率，再用钱加速」。选择平台时只看两件事：你的用户在哪个平台，以及你要的是曝光还是成交。

平台最适合的目标常见计费适合的产品什么时候不该投
百度竞价线索、成交点击 1–30 元本地服务、B2B、教育、装修客单价低于 300 元时通常算不过来
巨量引擎（抖音）曝光、下载、成交千次曝光 20–60 元电商、App、游戏、课程没有能持续产出素材的人
腾讯广告（朋友圈）线索、曝光千次曝光 25–80 元本地生意、教育、金融预算低于 1 万，跑不出数据
小红书聚光种草、搜索占位点击 1–5 元消费品、美妆、家居、旅拍产品没有「可被拍出来」的卖点
知乎知+线索点击 2–10 元高客单、专业服务需要大量曝光的时候
美团/点评推广通到店、成交点击 1–8 元餐饮、美容、维修、教育纯线上业务（无实体店）
投放前必须先算清楚三个数①你的客单价和毛利率；②当前落地页的转化率；③由此推出的「能承受的最高获客成本」。这三个数算不出来就投，基本等于把钱交给平台做实验。用本站预算 & ROI 计算器可以直接算。

90 天国内推广排期表

如果你现在什么都没做，下面是一个可以直接照抄的节奏。核心思路：第 1 个月打地基，第 2 个月铺内容，第 3 个月才开始花钱。

阶段重点动作产出可以花的钱
第 1–2 周埋点（UTM）、落地页优化、品牌地基（官网/百科/公众号/企业微信）一条可衡量的转化路径0 元
第 3–4 周搜索词挖掘 + 建 10 个落地页；知乎回答 15 条；小红书/短视频试更 10 条首批内容 + 第一批真实反馈0 元
第 2 个月把反馈最好的内容方向放大；固定内容生产节奏；开始沉淀私域稳定的自然流量来源0–1000 元（可选达人试水）
第 3 个月选 1–2 个渠道小预算投放（3–7 天），算出真实获客成本一份「哪个渠道值得加投」的数据结论按预算的 30% 试投
第 3 个月后跑正的渠道加投，跑不正的停掉；老内容定期更新维护可持续的获客模型按 ROI 决定

常见问题

我是做 To B 生意的，是不是不用做小红书抖音？

不必投入主要精力，但值得「占位」。B2B 的决策者也是普通人，他们刷到你的内容时会留下印象，这和后面搜索你公司名时的信任度有关。建议做法：把已有的公众号长文改写成短视频发几条，成本很低，主要作用是让客户「搜你的时候能搜到东西」。

预算只有 1000 元，应该花在哪？

不要分散。1000 元只够测一个渠道的一个素材，建议花在你判断「意向最接近成交」的那一个上（比如本地生意投美团推广通、B2B 投百度竞价的一小组长尾词）。目标是拿到「一次点击/一条线索多少钱」的真实数据，而不是追求效果。

内容写不出来怎么办？

把你被客户问过的问题列成清单——那就是最好的选题库。如果你还没有客户，去搜索引擎的下拉框、相关搜索、社区的提问里抄。每个问题都能写成一页内容，30 个问题足够撑两个月。

要不要找代运营或者推广服务商？

如果你的预算在 1 万元/月以下，通常不建议：代运营的服务费会吃掉大部分预算，而效果依赖的还是你自己的产品卖点和素材。更划算的做法是找一个「帮你做素材/剪视频」的兼职，策略和账户自己盯。预算足够大、且你完全没时间时再考虑代运营，并且一定要看真实案例的数据（不只看案例名字）。
